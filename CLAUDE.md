# CLAUDE.md - nocturnation-docs

Agent-authoring conventions for this repository. These are instructions for any LLM agent writing or editing documentation here; they are not part of the published docs surface.

## Language

- **UK English throughout** (colour, behaviour, organise, etc.). Applies to body text, code comments, and commit messages.
- **Harvard referencing** for external citations; `file:line` form for code references.

## Typography

- **Minus signs `-`, not em dashes `—`.** ASCII hyphen-minus only. Applies to both new files and edits to existing ones.
